A NOTE ON RESULTS

Deobfuscation helps make code easier to inspect. Review the output before relying on it; transformations and inferred names are not a guarantee of behavior or intent.

YOUR CODE, YOUR CHOICE

Know where processing happens.

The deterministic desktop engine runs locally. Android Quick triage and Safe clean run offline; Full mode sends the job to your paired desktop.

Optional remote AI services can receive code when selected. Review the provider’s terms and your configuration before enabling them. Pair the Android companion only on a trusted network.

Requires Linux x86-64 with WebKitGTK 4.1 and GTK 3; the deb and rpm declare those dependencies. Third-party license notices and full license texts are included as THIRD_PARTY_NOTICES.md and THIRD_PARTY_LICENSES.md.

The binaries are not OS-code-signed. Each release carries a Sigstore signature over SHA256SUMS; verify it and the checksums before running. AppImage installs on 3.2.15 or newer can update from Settings → About.
